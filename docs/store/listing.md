## 详细描述

**下载守护**是一个纯本地运行的下载工具：没有账号、没有广告、没有会员，也不会上传你的下载记录。

**多线程与断点续传**
把一个文件拆成多段并行下载，网络抖动或切网后从断点继续，不用从头再来。并发数可以按网络情况调整，从 1 到 64 任意设置。

**网页链接嗅探**
在应用内打开下载站页面，自动识别页面里的真实文件地址，省去「右键复制链接」这一步。页面加载使用系统 WebView，只在本地解析，不上传页面内容。

**站点规则：专治 403**
不同下载站对 Referer、Cookie、User-Agent 的要求不一样。你可以按域名保存一套规则：Referer 取页面还是直链、Cookie 合并哪些域、用哪个 UA、初始并发多少、文件名怎么排。规则可导入导出、可测试，纯声明式配置，不执行任何代码。

**浏览器链接识别（可选，默认关闭）**
在浏览器里点击或长按一个下载链接（.apk、.zip、.pdf、.mp4 等），自动加入下载候选，省去长按复制的步骤。该能力由无障碍服务提供，只对浏览器生效，不读取聊天与社交应用、不记录浏览历史、不模拟点击；随时可在设置页或系统设置中关闭。不开也能正常使用：手动粘贴或系统分享照常可用。

**分享即下载**
在浏览器或网盘应用里分享链接到「下载守护」，直链直接建任务，分享页自动进入嗅探模式。

**下载完成后校验**
支持旁挂 `.sha256` / `.md5` 校验文件，收尾阶段在本地计算哈希；校验结果只展示给你，不自动执行任何文件。

**我们不做的事**
- 不要求注册，不收集手机号、通讯录、位置
- 不接入广告、统计、推送 SDK
- 不提供「破解」「会员加速」「绕过付费」能力
- 不上传你的链接、Cookie 或下载记录

**说明**
请只下载你有权获取的文件，并遵守目标网站的服务条款。本应用不提供任何内容源，也不对下载内容的合法性负责。
