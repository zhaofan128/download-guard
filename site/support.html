Support

帮助与联系

先看下面几条，八成的「下不动」都在里面。仍然解决不了，把版本号、站点域名和报错原文发给我们。

安装时提示「未知来源」或「已阻止安装」

未在应用商店上架前，安装包通过 GitHub 分发，系统默认会拦。在提示里点「设置」，允许当前应用（浏览器或文件管理器）安装未知应用，再返回继续安装。 安装完成后建议把该权限关掉。商店版不申请安装权限，也无法静默安装其他 APK。

某个站点一直 403 / 401，浏览器能下、应用下不了

多数是防盗链：站点要求请求带上正确的 Referer，或校验登录后的 Cookie。 在「高级」里填一次 Referer（通常是那个页面的地址），或在「站点规则」里按域名保存下来，下次自动套用。 Cookie 可在浏览器开发者工具或站点规则里粘贴，注意只填 name=value，不要带 Path、Domain 这些属性。

下载速度上不去，或者到 99% 卡住

两个方向。一是把并发调低：部分站点对同一 IP 的并发连接有限制，连接越多越容易被限速甚至拒绝，试试从 32 降到 8 甚至 4。 二是目标服务器不支持 Range，只能单线程顺序下载，收尾阶段本来就会慢一些。可以换网络（Wi-Fi ↔ 移动数据）再试，任务会从断点继续。

下载完了，文件管理器里找不到

商店版把文件写在应用私有目录 Android/data/com.dlguard/files/Download，这是 Android 11 之后对未申请全盘权限的应用的标准做法。 在应用的下载列表里点「打开」，或长按选择「分享 / 导出」保存到相册或公共目录。 卸载应用会连同这些文件一起删除，请先导出。

换了手机 / 重装了，任务列表没了

本应用没有云端同步，任务与历史只存在本机，重装即清空。站点规则可以在规则页导出 JSON，换设备后导入即可复用。

开了「浏览器链接识别」，在微信里点链接没反应

这是设计如此。该服务只对浏览器生效，包名白名单不含任何聊天与社交应用。在浏览器里点击或长按一个指向文件的链接（.apk、.zip、.pdf、.mp4 等）才会被识别。 若浏览器里也没反应：确认服务在「系统设置 → 无障碍」中处于开启状态，并且该浏览器在支持列表内。

你们会不会记录我下载了什么

不会。没有账号体系，没有统计 SDK，下载记录只写在本机数据库。你可以断网使用除下载以外的全部功能来验证这一点。 详见 隐私政策。

怎么彻底删除我的数据

应用内删除单条任务，或「设置 → 清除数据」，或直接卸载应用。我们这边没有任何你的数据副本可供删除，因为从未上传。
