本政策适用于 Android 应用「下载守护」（包名 com.dlguard，以下称「本应用」）。 我们尽量用直白的语言说明：本应用做什么、不做什么、数据在哪里。

一、一句话概括

本应用是一个本地下载工具。它不要求注册账号，不收集个人身份信息，不接入广告或统计 SDK， 不把下载记录、链接、Cookie 上传到任何开发者服务器。所有任务、设置与文件都保存在你的设备上。

二、我们不收集什么

  • 不收集姓名、手机号、身份证号、通讯录、短信、位置、IMEI、MAC 等个人信息。
  • 不收集你在其他应用中的使用行为。
  • 不读取通知内容（商店版已移除通知监听能力）。
  • 不读取微信、QQ、钉钉等聊天与社交应用的内容（商店版的无障碍服务只对浏览器生效，见第四节）。
  • 不读取剪贴板（商店版不会在后台或回到前台时自动读取剪贴板）。
  • 不遍历已安装应用列表；仅在系统清单里声明「是否存在浏览器」，用于「用浏览器打开」这一可选入口，不上传。
  • 不接入第三方广告、统计、崩溃上报、推送 SDK。

三、本机保存的数据

数据 位置 用途 删除方式
下载任务与历史记录 应用私有数据库（Room） 展示进度、续传、重新下载 应用内删除单条，或清除应用数据
设置项 应用私有 DataStore 记住并发数、通知、主题等偏好 同上
站点规则 应用私有 DataStore 按域名套用 Referer、Cookie 来源、UA、并发与文件名模板 规则页删除或清空
下载的文件 应用私有外部目录 Android/data/com.dlguard/files/Download 你下载的内容 应用内删除，或卸载应用
崩溃现场（可选） 应用私有目录 本地排查闪退，不上传 设置页清除

卸载本应用会删除上述全部数据，包括已下载的文件。请在卸载前把需要的文件导出到公共目录，或通过系统分享保存到别处。

四、权限与用途

商店版只申请以下 6 项权限，逐条说明用途与拒绝后的后果：

权限 用途 拒绝的后果
INTERNET 连接你输入的下载地址，传输文件 无法下载
ACCESS_NETWORK_STATE 判断当前是否 Wi-Fi，用于「仅 Wi-Fi 下载」 仅 Wi-Fi 限制失效
POST_NOTIFICATIONS 显示下载进度与完成通知（Android 13 及以上） 收不到进度与完成提醒，下载仍会继续
FOREGROUND_SERVICE 退到后台时保持下载 退到后台后下载可能被系统暂停
FOREGROUND_SERVICE_DATA_SYNC 同上，声明前台服务类型（Android 14 及以上必需） 同上
WAKE_LOCK 下载收尾（写盘、校验哈希）时防止休眠中断 大文件收尾可能失败

本应用不申请：所有文件访问（MANAGE_EXTERNAL_STORAGE）、安装应用（REQUEST_INSTALL_PACKAGES）、 通知使用权、读取剪贴板、开机自启、精确闹钟、Shizuku 特权。

无障碍服务（可选，默认关闭）

商店版包含一个名为「下载链接识别」的无障碍服务，默认关闭， 只有你在设置页手动开启后才工作。

做什么 你在浏览器里点击或长按下载链接时，读取该链接的地址并加入下载候选，省去「长按复制 → 切回应用 → 粘贴」。
生效范围 只在浏览器应用内。包名白名单为 Chrome、Edge、Firefox、UC、夸克、QQ 浏览器以及华为 / 小米 / OPPO 自带浏览器等，不含任何聊天或社交应用。
事件范围 只订阅「点击」与「长按」两种事件。不订阅页面切换与内容变化，系统不会把页面内容持续推送给本服务。
不做什么 不读取键盘输入、不模拟点击、不操作其他应用、不记录浏览历史、不截图、不联网上传。
数据去向 命中的链接只写入本机内存中的候选列表；你点击「下载」后才开始网络请求。
如何关闭 设置页开关直接停用；或在「系统设置 → 无障碍 → 下载链接识别」中关闭。

关闭该服务不影响其他任何功能：你仍然可以手动粘贴链接，或从浏览器通过系统分享发送给本应用。

五、网络请求与请求头

  1. 本应用直接连接你提供的下载地址，不经过开发者服务器，也没有中转、解析或云端加速服务。
  2. 为了通过防盗链校验，你可能在「高级请求头」或「站点规则」中填写 Referer、Cookie、User-Agent。这些值只会发送给对应的下载站点，不会发送给开发者或任何第三方。
  3. 网页嗅探使用系统 WebView 打开你指定的页面，页面加载行为受该网站自身隐私政策约束。本应用只在本地解析页面中的链接，不上传页面内容。
  4. 本应用允许 HTTP 明文连接，因为部分下载站只提供 HTTP 直链。传输内容是否加密取决于目标站点，请优先使用 HTTPS 地址。
  5. 站点规则中的自定义 Cookie 保存在应用私有 DataStore，未 root 的设备上其他应用无法读取，但未做 Keystore 加密；导出的规则文件会自动清空自定义 Cookie 的值。

六、数据的共享、转让与公开披露

我们不共享、不转让、不公开披露你的任何数据。以下情形除外：

  • 你主动通过系统分享面板把文件或文本分享给其他应用；
  • 依据法律法规、司法或行政机关的强制性要求。

七、第三方组件

本应用使用了以下开源库，它们仅在本机运行，不承担数据收集功能：

  • OkHttp —— 网络请求
  • AndroidX / Jetpack Compose / Room / WorkManager / DataStore —— 界面、数据库、任务调度
  • Rhino —— 仅完整版使用；商店版已移除脚本插件

本应用不包含广告 SDK、统计分析 SDK、社交登录 SDK、推送 SDK。

八、未成年人保护

本应用不面向 14 周岁以下儿童单独提供服务，不收集儿童个人信息。未成年人应在监护人指导下使用。

九、你的权利

  • 查询与更正：设置页可查看全部本地配置。
  • 删除：任务、记录、规则均可在应用内删除；清除应用数据或卸载应用会删除全部本地数据。
  • 撤回同意：在系统设置中关闭通知、网络权限，或卸载应用。
  • 导出：站点规则支持导出 JSON；下载文件可通过系统分享导出。
  • 投诉：通过第十二节的邮箱联系我们，15 个工作日内答复。

十、数据安全

  • 应用不建立账号体系，不持有你的任何凭据。
  • 本地数据依赖 Android 应用沙箱隔离。
  • 下载文件的完整性校验（SHA-256 / 签名）在本地完成，结果只显示给你。

请注意：任何软件都无法保证绝对安全。请勿在不可信站点填写账号密码，勿下载来源不明的可执行文件。

附：商店版与完整版的差异

两个版本包名相同，但能力范围不同：

能力 完整版 商店版
无障碍服务 浏览器 + 可选社交应用内嵌页（点击与页面扫描） 仅浏览器，仅点击事件
通知监听 从其他应用的通知里取链接 移除
